# Brand assets: not MIT

The logos, icons and ornaments in this folder belong to the Sinapse Zero brand. They are included so the
showcase renders as designed, but they are **not** covered by the repository's MIT license.

The wordmark is set in [Orbitron](https://fonts.google.com/specimen/Orbitron) (SIL Open Font License 1.1).

To use the framework under your own brand, replace these files (same names, same formats) and the
values in `packages/brand/src/tokens.ts`.
